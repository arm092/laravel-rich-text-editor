# Toolbar and formatting

The standard profile includes undo, redo, headings H2–H4, bold, italic, underline, strikethrough, inline code, lists, blockquotes, code blocks, horizontal rules, links, URL images, clear formatting, and code view.

Links support relative URLs plus HTTP, HTTPS, mailto, and tel by default. Links opened in a new tab receive `noopener noreferrer`. Images accept HTTP or HTTPS URLs, require alternative text or an explicit decorative choice, and support left, center, and right alignment. File uploads and a media manager are outside `0.1.x`.
