# Livewire integration

Bind the Blade component like a native field:

```blade
<x-rich-text-editor wire:model="form.content" />
```

The editor dispatches native `input` events from its backing textarea. Livewire owns that textarea while `wire:ignore` protects only the DOM generated by the editor engine. This preserves deferred form submission and supports model modifiers.

The runtime listens for Livewire navigation and reconciles externally changed values after reset or morph operations. Do not add `wire:ignore` to the complete component root, because that would prevent Livewire from updating the backing field and validation state.
